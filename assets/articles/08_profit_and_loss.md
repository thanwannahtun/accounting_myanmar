# အမြတ်အရှုံးစာရင်းကို ခွဲခြမ်းစိတ်ဖြာခြင်း (Profit & Loss / Income Statement)

> **"လုပ်ငန်းတစ်ခုသည် အမှန်တကယ် ငွေရှာပေးနေသလား သို့မဟုတ် ငွေကုန်ပေါက် ဖြစ်နေသလားကို အမြတ်အရှုံးစာရင်း (P&L) ကသာ အတိအကျ ဖြေကြားနိုင်ပါသည်။"**

---

## ၁။ အမြတ်အရှုံးစာရင်း (P&L Statement) ဆိုတာ ဘာလဲ

**အမြတ်အရှုံးစာရင်း (Profit and Loss Statement သို့မဟုတ် Income Statement)** သည် သတ်မှတ်ထားသော ကာလတစ်ခုအတွင်း (ဥပမာ - တစ်လအတွင်း၊ သုံးလအတွင်း သို့မဟုတ် တစ်နှစ်အတွင်း) လုပ်ငန်းတစ်ခု၏-
* ရရှိခဲ့သော **စုစုပေါင်း ဝင်ငွေ (Total Revenue)**
* ကုန်ကျခဲ့သော **စုစုပေါင်း စရိတ်များ (Total Expenses)** နှင့်
* နောက်ဆုံး ကျန်ရှိသော **အသားတင် အမြတ် သို့မဟုတ် အရှုံး (Net Profit or Loss)**

တို့ကို စနစ်တကျ တွက်ချက်ဖော်ပြပေးသော ဘဏ္ဍာရေး အစီရင်ခံစာ ဖြစ်သည်။

---

## ၂။ အဆင့်ဆင့် အမြတ်တွက်ချက်ပုံ (Step-by-Step Profit Levels)

စီးပွားရေးတွင် "အမြတ်" ဟူသော စကားလုံးတစ်လုံးတည်းကိုပင် အဆင့် (၃) ဆင့်ဖြင့် ခွဲခြားနားလည်ရပါသည်-

> 💵 **၁။ စုစုပေါင်း အရောင်းရငွေ (Sales Revenue)**  
> ➖ **ရောင်းကုန်ပစ္စည်း မူလတန်ဖိုး စရိတ် (Cost of Goods Sold - COGS)**  
> ⬇️  
> 🟢 **(က) စုစုပေါင်းအမြတ် (GROSS PROFIT)**

> ➖ **လုပ်ငန်းလည်ပတ်စရိတ်များ (Operating Expenses - OPEX)**  
> *(ဝန်ထမ်းလစာ၊ ဆိုင်ခန်းခ၊ မီးဖိုး၊ ကြော်ငြာစရိတ်)*  
> ⬇️  
> 🔵 **(ခ) လုပ်ငန်းလည်ပတ်မှုအမြတ် (OPERATING PROFIT)**

> ➖ **အခွန်များနှင့် အတိုးစရိတ်များ (Tax & Interest)**  
> ⬇️  
> 🏆 **(ဂ) အသားတင်အမြတ် (NET PROFIT)**

---

## ၃။ အရေးကြီးသော အမြတ်ရာခိုင်နှုန်း အချိုးများ (Profit Margins)

### ၁။ စုစုပေါင်းအမြတ် ရာခိုင်နှုန်း (Gross Profit Margin)
> 💡 **Gross Margin % = (Gross Profit ÷ Revenue) × 100**

* သင့်ကုန်ပစ္စည်း ရောင်းဈေးသတ်မှတ်ချက်သည် ဝယ်ရင်းဈေးထက် မည်မျှအမြတ်တင်ထားနိုင်သည်ကို ဖော်ပြသည်။
* လက်လီဆိုင်များတွင် ပုံမှန်အားဖြင့် **25% မှ 45% ကြား** ရှိတတ်သည်။

### ၂။ အသားတင်အမြတ် ရာခိုင်နှုန်း (Net Profit Margin)
> 📊 **Net Margin % = (Net Profit ÷ Revenue) × 100**

* စရိတ်အားလုံး နှုတ်ပြီးပါက ရောင်းရငွေ ၁၀၀ ကျပ်တိုင်းတွင် ပိုင်ရှင်လက်ထဲ အသားတင် အမြတ်ငွေ မည်မျှကျန်ရှိသည်ကို တိုင်းတာသည်။

---

## ၄။ မြန်မာ့လုပ်ငန်း နမူနာ P&L ရှင်းတမ်း

**"ရွှေပြည်သစ်" ကော်ဖီဆိုင်၏ ၂၀၂၆ ခုနှစ်၊ မတ်လ (၁ လစာ) အမြတ်အရှုံးစာရင်း:**

| စာရင်းအကြောင်းအရာ | ပမာဏ (ကျပ်) | ရာခိုင်နှုန်း (%) |
| :--- | :---: | :---: |
| **အရောင်းရငွေ (Sales Revenue):** | | |
| ကော်ဖီနှင့် မုန့်ရောင်းရငွေ စုစုပေါင်း | **၁၅,၀၀၀,၀၀၀** | 100% |
| **ရောင်းကုန်တန်ဖိုးစရိတ် (Cost of Goods Sold):** | | |
| ကော်ဖီစေ့၊ နို့ဆီ၊ သကြား၊ မုန့်ကုန်ကြမ်းစရိတ် | (၆,၀၀၀,၀၀၀) | 40% |
| **စုစုပေါင်းအမြတ် (Gross Profit)** | **၉,၀၀၀,၀၀၀** | **60%** |
| | | |
| **လုပ်ငန်းလည်ပတ်စရိတ်များ (Operating Expenses):** | | |
| ဝန်ထမ်း (၄) ဦး လစာစရိတ် | (၂,၄၀၀,၀၀၀) | 16% |
| ဆိုင်ခန်းငှားရမ်းခ | (၁,၅၀၀,၀၀၀) | 10% |
| လျှပ်စစ်မီးနှင့် ရေ အသုံးစရိတ် | (၆၀၀,၀၀၀) | 4% |
| ဆိုရှယ်မီဒီယာ ကြော်ငြာစရိတ် | (၃၀၀,၀၀၀) | 2% |
| ရုံးသုံးနှင့် သန့်ရှင်းရေးပစ္စည်းစရိတ် | (၂၀၀,၀၀၀) | 1.3% |
| *စုစုပေါင်း လည်ပတ်စရိတ်* | *(၅,၀၀၀,၀၀၀)* | *33.3%* |
| | | |
| **လုပ်ငန်းလည်ပတ်မှုအမြတ် (Operating Profit)** | **၄,၀၀၀,၀၀၀** | **26.7%** |
| ကုန်သွယ်လုပ်ငန်းခွန် (Commercial Tax - 5%) | (၇၅၀,၀၀၀) | 5% |
| **အသားတင်အမြတ် (Net Profit)** | **၃,၂၅၀,၀၀၀** | **21.7%** |

## ၅။ P&L ဖတ်ရှုပြီး လုပ်ငန်းတိုးတက်အောင် လုပ်ဆောင်နည်း

1. **Gross Margin နည်းနေပါက:** ကုန်ကြမ်းဝယ်ယူရာတွင် ပိုမိုဈေးသက်သာသော လက်ကားကုန်သည်ကို ရှာဖွေပါ သို့မဟုတ် ကုန်ပစ္စည်းလေလွင့်မှုကို လျှော့ချပါ။
2. **Net Profit နည်းနေပါက:** မလိုအပ်သော လည်ပတ်စရိတ်များ (ဥပမာ- အလွန်အကျွံ မီးသုံးစွဲမှု၊ ထိရောက်မှုမရှိသော ကြော်ငြာများ) ကို ဖြတ်တောက်ပါ။
3. **လစဉ် နှိုင်းယှဉ်ပါ:** ပြီးခဲ့သောလကထက် ဝင်ငွေတိုးသော်လည်း အမြတ်ကျနေပါက မည်သည့်စရိတ် ခေါင်းစဉ် ခုန်တက်သွားသည်ကို P&L က ချက်ချင်း ညွှန်ပြပေးမည် ဖြစ်သည်။
